# تنفيذ المخزن الدائري (Circular Buffer)

## وصف المشروع  
 تطبيق عملي للمخزن الدائري باستخدام لغة c 

## هيكل المشروع  
يحتوي المستودع على ملفين:  
- `main.c` : الكود المصدري الكامل.  
- `README.md` : ملف الشرح الخاص بالمشروع.

## طريقة العمل  
يقوم البرنامج بما يلي:  
1. يطلب اسم المستخدم عبر الإدخال القياسي.  
2. يضيف الى الاسم السلسلة`CE-ESY`  
3. يخزّن كل حرف من السلسلة الناتجة في المخزن.  
4. يقرأ الحروف من المخزن ويعرضها متصلة.  
5. يتحقق من فراغ المخزن بعد انتهاء القراءة.
6. إذا كان الحجم أصغر من عدد الحروف المطلوبة، تظهر رسالة `Buffer Overflow` 
7. إذا كان الحجم كافياً، تتم الكتابة والقراءة كاملة.
## مثال للخرج  
عند تشغيل الكود بحجم مخزن 5 وإدخال الاسم `Ali`: 
Alice-sy
## دوال المخزن  
- `init()` : تهيئة المؤشرات والعداد.  
- `isFull()` : فحص الامتلاء.  
- `isEmpty()` : فحص الفراغ.  
- `write()` :  `Buffer Overflow` إضافة عنصر أو طباعة
- `read()` :`Buffer Underflow` سحب عنصر أو طباعة
